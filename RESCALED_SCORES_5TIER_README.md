# Rescaled Scores: 5-Tier System

## Overview

The BERTJE training pipeline now uses a **5-tier rescaled score system** that provides granular quality classification while maintaining backward compatibility with the traditional 3-tier system.

## 5-Tier Confidence System

### Score Ranges

| Tier | Score Range | Interpretation | Typical % |
|------|-------------|----------------|-----------|
| **Core** | 1.5 - 2.0 | Highest quality, perfect topic match | 10-15% |
| **Moderate** | 1.0 - 1.5 | Good quality, clear relevance | 15-25% |
| **Weak** | 0.5 - 1.0 | Borderline relevance, some connection | 30-40% |
| **Context** | 0.25 - 0.5 | Weak signal, contextual mention only | 15-25% |
| **Noise** | 0.0 - 0.25 | No meaningful signal, unrelated | 10-20% |

## Training Data Options

### Option 1: Conservative (Core Only)
```python
# Use only highest quality data
train_data = pd.read_csv('scores_core_confidence.csv')
```
- **Pros**: Highest precision, cleanest training signal
- **Cons**: Limited data, may not generalize well
- **Use when**: You have enough core data (>1000 examples)

### Option 2: Standard (Core + Moderate)
```python
# Use high-quality data
core_df = pd.read_csv('scores_core_confidence.csv')
moderate_df = pd.read_csv('scores_moderate_confidence.csv')
train_data = pd.concat([core_df, moderate_df])

# OR use compatibility file
train_data = pd.read_csv('scores_high_confidence.csv')
```
- **Pros**: Good balance of quality and quantity
- **Cons**: None, this is the recommended approach
- **Use when**: Standard training scenario

### Option 3: Inclusive (Core + Moderate + Weak)
```python
# Use all reasonably relevant data
core_df = pd.read_csv('scores_core_confidence.csv')
moderate_df = pd.read_csv('scores_moderate_confidence.csv')
weak_df = pd.read_csv('scores_weak_confidence.csv')
train_data = pd.concat([core_df, moderate_df, weak_df])
```
- **Pros**: Maximum data, better coverage of edge cases
- **Cons**: May include noise, harder to learn clear boundaries
- **Use when**: You need more training data

### Option 4: Pseudo-Labeling (High + Weak as pseudo)
```python
# Labeled data: Core + Moderate
labeled_data = pd.read_csv('scores_high_confidence.csv')

# Pseudo-labeled data: Weak (with soft labels)
pseudo_data = pd.read_csv('scores_weak_confidence.csv')
pseudo_data['is_pseudo'] = True
```
- **Pros**: Leverages borderline examples with appropriate weighting
- **Cons**: More complex training setup
- **Use when**: You want to use semi-supervised learning

### Option 5: Contrastive Learning (High vs Context/Noise)
```python
# Positive examples: Core + Moderate
positive_data = pd.read_csv('scores_high_confidence.csv')
positive_data['label'] = 1

# Negative examples: Context + Noise
negative_data = pd.read_csv('scores_no_confidence.csv')
negative_data['label'] = 0
```
- **Pros**: Clear distinction between relevant and irrelevant
- **Cons**: Ignores the middle ground (weak)
- **Use when**: You want binary classification

## Prediction with 5-Tier System

### Updated Cell 68 Logic

#### Ordinal Classification (5 levels)
```python
def score_to_ordinal(score):
    """Convert continuous rescaled score to 5-level ordinal"""
    if score < 0.25:
        return 0  # Noise
    elif score < 0.50:
        return 1  # Context
    elif score < 1.00:
        return 2  # Weak
    elif score < 1.50:
        return 3  # Moderate
    else:
        return 4  # Core
```

#### Confidence Assignment (5 tiers)
```python
def assign_confidence(row):
    """Assign 5-tier confidence based on score + margin"""
    score = row['bertje_primary_score']
    margin = row['bertje_margin']

    # Core: excellent score AND margin
    if score >= 1.50 and margin > 0.30:
        return 'core'
    # Moderate: good score AND margin
    elif score >= 1.00 and margin > 0.20:
        return 'moderate'
    # Weak: decent score AND margin
    elif score >= 0.50 and margin > 0.10:
        return 'weak'
    # Context: low score OR small margin
    elif score >= 0.25 or margin > 0.05:
        return 'context'
    # Noise: everything else
    else:
        return 'noise'
```

## Benefits of 5-Tier System

### 1. Granular Quality Control
- Can select exactly which quality levels to include
- Easy to experiment with different tier combinations
- Clear understanding of data composition

### 2. Flexible Training Strategies
- Use different tiers for different purposes
- Core for supervised learning
- Weak for pseudo-labeling
- Context/Noise for negative examples

### 3. Better Analysis
- Understand model performance at each quality level
- Identify where model struggles (e.g., weak vs moderate)
- Fine-tune thresholds based on 5-tier distribution

### 4. Backward Compatible
- 3-tier files still generated automatically
- Existing workflows continue to work
- Can gradually migrate to 5-tier system

## Comparison: 3-Tier vs 5-Tier

### 3-Tier (Old)
```

Low (0.5-1.0)    ████████████ 35%
None (< 0.5)     ██████████   30%
```
- Simple but coarse
- Hard to distinguish quality within "High"
- Mixes very different quality levels

### 5-Tier (New)
```
Core (1.5-2.0)      ████       15%
Moderate (1.0-1.5)  ██████     20%
Weak (0.5-1.0)      ████████   35%
Context (0.25-0.5)  ████       15%
Noise (0-0.25)      ███        15%
```
- More granular distinctions
- Can see quality distribution clearly
- Can use different tiers strategically

## Summary

The 5-tier rescaled score system provides:

✅ **Granular control** - 5 quality levels instead of 3
✅ **Flexible training** - Mix and match tiers as needed
✅ **Better analysis** - Understand performance by tier
✅ **Backward compatible** - 3-tier files still generated
✅ **Clearer thresholds** - 0.25, 0.5, 1.0, 1.5 boundaries

**Recommended approach**: Start with Core + Moderate (high confidence file) for training, then experiment with including Weak for pseudo-labeling if you need more data.
